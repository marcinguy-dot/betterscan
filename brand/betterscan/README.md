## Why “BetterScan”

BetterScan is multi-engine code security that aims for deeper, more accurate results—graph-aware analysis (Joern / Fraunhofer CPG) plus a full self-hosted web platform. One product name for CLI, worker, and UI.

## Heritage

BetterScan continues the **Contender** project line shown at **Black Hat MEA 2025** in **Saudi Arabia**. Intermediate open-source names included Checkmate and Lattice.
